DIVASTRA-LIKE — MODELE DE BOUTIQUE DYNAMIQUE

Fichiers:
- index.html : structure de la boutique
- styles.css : design responsive
- script.js : contenu dynamique, recherche, filtres, produits, panier et WhatsApp

PERSONNALISATION RAPIDE:
1. Ouvrir script.js avec VS Code.
2. Modifier CONFIG pour le nom de votre marque, email, WhatsApp, adresse et Instagram.
3. Modifier HERO_SLIDES pour les textes et images du grand bandeau.
4. Modifier PRODUCTS pour les noms, prix, catégories, tailles, descriptions et images.
5. Pour une image locale, placez vos images dans un dossier images/ puis mettez par exemple:
   image: "images/robe-01.jpg"
6. Ouvrir index.html dans le navigateur.

FONCTIONS INCLUSES:
- menu responsive
- recherche de produits
- filtres par catégorie
- slider hero automatique
- fiche produit / quick view
- panier persistant avec localStorage
- total panier
- bouton commande WhatsApp
- newsletter de démonstration
- sections histoire, blog et contact

IMPORTANT:
Ce modèle est indépendant du site de référence. Il reprend des idées de structure e-commerce similaires, avec un contenu et une identité visuelle propres.
